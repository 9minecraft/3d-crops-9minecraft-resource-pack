## About this resource pack

3D Crops 9minecraft Resource Pack replaces flat, cross-shaped farming plants with three-dimensional models. It gives every farm extra depth while keeping the standard 16x pixel art look. The pack changes how wheat, root vegetables, and wild plants appear in the ground across every growth stage. Because this pack only alters 3D block models without changing default textures, you can run it smoothly alongside your favorite texture packs.
